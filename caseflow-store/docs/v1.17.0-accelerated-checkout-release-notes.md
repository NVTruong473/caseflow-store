# v1.17.0 - Isolated Accelerated Checkout

Release date: 2026-07-28

Production: `https://caseflow-store.vercel.app`

Vercel deployment: `dpl_79ccQjZHA3KBTvGP2JQ48SN8eHLX`

## Summary

`v1.17.0` adds a product-detail Buy Now path for customers who already know
which edition and quantity they want. It skips the cart review step without
turning checkout into a one-click order: customer identity, profile, delivery,
payment method, voucher, stock, price, VAT, fees, and final total remain
validated through the existing server-owned checkout boundary.

The release also ships two bounded, dependency-free commerce interactions and a
complete redraw of the project layer architecture.

## Accelerated Checkout

- Product detail now presents `Mua ngay / Buy now` as the primary action and
  `Them vao gio / Add to cart` as the secondary action.
- Buy Now carries only edition ID and quantity in a strict same-origin URL
  intent. It carries no price, total, discount, customer data, payment state,
  or authorization claim.
- Anonymous customers return to the exact valid direct-purchase selection
  after signing in.
- Malformed intent fails closed and never silently falls back to cart checkout.
- `/api/cart/validate` reloads active edition, stock, and trusted price before
  display. `/api/orders` recalculates every order amount before persistence.
- Official checkout and the isolated QR experience use the same validated
  direct selection.
- Buy Now does not add, merge, replace, or clear saved cart lines. A successful
  direct order records and displays that cart-preservation behavior.
- Standard multi-item cart checkout retains its existing clear-after-success
  behavior.

## Commerce Motion

- Added a bounded product-cover magnifier for fine pointers.
- Added a category-cover reveal with stable geometry.
- Both interactions use local cover assets, keyboard-visible behavior,
  touch fallbacks, and `prefers-reduced-motion`.
- No Originkit account, MCP, remote script, or new runtime dependency is
  required.

## Architecture

- Added `docs/layer-architecture-v1.17.md`.
- Documented the complete browser, Vercel, presentation, Route Handler
  controller, application use-case, domain/policy, repository, Supabase/Auth,
  payment, notification, and PostgreSQL layers.
- Documented cart and Buy Now as separate browser-state entry points that
  converge at trusted server validation.
- Mapped MVC responsibilities to the actual Next.js modular monolith without
  claiming a textbook MVC folder structure or microservice deployment.

## Known Boundaries

- No real payment, bank account, wallet, settlement, refund, shipping carrier,
  warehouse, or map tracking provider is connected.
- The QR checkout experience remains an isolated showroom flow and cannot
  create or pay an order.
- External email/SMS delivery remains buyer-configured and fail-closed by
  default.
- The shared admin/staff operations secret remains a showroom safeguard, not
  enterprise MFA.
- Two password-assurance cases required one retry in the full local sequential
  run; the entire focused suite then passed cleanly in isolation.
