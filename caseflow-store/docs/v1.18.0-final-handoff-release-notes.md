# CaseFlow Books v1.18.0

## Final Public And Academic Handoff

`v1.18.0` completes the approved post-showroom handoff without reopening broad
feature development. The release adds an opt-in storefront walkthrough,
hardens the Production payment-simulation boundary, and provides a reproducible
clean-source export process for downstream evaluation and licensed delivery.

## Storefront Introduction

- Adds a user-initiated 4:16 Vietnamese walkthrough to the homepage.
- Uses local MP4, poster, and WebVTT caption assets.
- Avoids autoplay and first-load media download through metadata-only preload.
- Supports keyboard focus containment, Escape/backdrop close, focus return,
  body-scroll lock, and responsive desktop/mobile containment.

## Production Safety

- Moves the payment-simulation environment check to the Route Handler boundary.
- Returns `404` in Production before payment-ID validation, authentication, or
  payment-service work.
- Keeps mock payment controls unavailable in Production even if development
  environment values are configured incorrectly.

## Clean Public Source Package

- Adds an allowlist-based exporter that preserves the development repository.
- Exports runtime source/assets, Supabase schema and migrations, a safe
  environment template, build configuration, proprietary `LICENSE`, and one
  documentation file (`README.md`).
- Generates a customer-data-free catalog and merchandising seed with 500 active
  book editions.
- Excludes internal plans, agent state, tests, reports, prompts, local
  environments, credentials, caches, build output, and obsolete mock data.
- Produces a complete tree inventory and machine-readable policy/security
  validation outside the public package.

## Academic Records

- Reconciles 24 eligible five-hour entries from 01/07/2026 through 28/07/2026,

## Explicit Boundaries

- QR practice and mock payment logic do not settle real funds.
- External email/SMS delivery remains disabled until a buyer supplies approved
  providers and monitored sender identities.
- Commercial deployment still requires buyer-owned legal review, catalog asset
  rights, merchant/payment onboarding, observability, backups, and operating
  runbooks.
- The clean source package is source-available under the included proprietary
  license; public access does not grant commercial deployment or resale rights.
